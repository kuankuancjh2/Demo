# 莫下面一个空

> Game Jam · 纸面笔画解谜
> 你扮演「莫」。走过的地面会消失，所以每一关都是一笔画：
> **起点 → 偏旁 → 门**，不能回头。

---

## 怎么跑

```
Tools\Godot.exe --path .
```

引擎是 **Godot 4.7.2**（已在 `Tools/`）。没有第三方依赖，不需要下载资源。

---

## 玩法

### 三条核心规则

1. **走过即消失。** 踩过的格子变成空白的纸，再也回不去。所以你在写的其实是一条**不自交的笔画**。
2. **步数是要花光的资源。** 每关给一个总步数，不是每回合刷新。走一步扣一步，扣完就输。
3. **门只认填好的字。** 空手走到门口不算通关——莫下面必须填一个偏旁。

于是每一关都是一道题：**在会消失的纸面上，画一条 起点 → 偏旁 → 门 的一笔画。**

### 操作

| 按键 | 作用 |
|---|---|
| `← ↑ → ↓` / `WASD` | 移动一格（1 步，树木要 2 步） |
| `F` | 拾取脚下的偏旁 / 汉字 |
| `1` / `2` | 使用第 1 / 2 格的偏旁 |
| `Q` / `E` | 抹掉第 1 / 2 格的偏旁（再也拿不回来） |
| `Z` | **撤回一笔**（放心试，`Z` 能退） |
| `R` | 重来本关 |
| `Esc` | 返回选关 |
| `N` | 结算画面 / 选关画面：下一关 / 随机关卡 |

`工` 和 `风` 要选目标：按 `1` 进入选择模式，`←↑` / `→↓` 换目标，`Enter` 确认，`Esc` 取消。

### 两种模式

**关卡模式（12 关，手设计）** — 主菜。全图可见，教学递进：
填空 → 绕行 → 尖刺 → 破墙 → 渡火 → 取舍 → 引火 → 双闸 → 火海 → 独木 → 重负 → 收笔。
每关都有步数上限和血量，部分关卡的最优解就是唯一的解。

**随机关卡** — 无限生成，全图可见。每张图都**保证可通**（生成器会先随出一条自避骨架当保底解）。

### 地形

| | 效果 |
|---|---|
| 地面 | 就是纸。走 1 步，然后消失 |
| 荆棘 | 走 1 步，−1 生命 |
| 树木 | 过不去，除非「艹」生效 |
| 障碍物 | 过不去，除非用「工」砸开 |
| 火 / 水 | 走 1 步，−1 生命（「石」生效时免疫） |
| 门 | 带着偏旁走上去 = 通关；空手走上去 = 困死 |

### 偏旁：主动效果 + 携带代价

偏旁既是你想要的那个结局，也是一路拖着你走的负担。**什么时候拿、什么时候抹掉，就是这个游戏的深度所在。**

| 偏旁 | 主动（消耗 1 步） | 携带代价 | 结局 |
|---|---|---|---|
| 火 | 烧掉相邻的荆棘和树木 | 引火烧身：使用后自己 −1 生命 | 焚 |
| 刂 | 清朝向一条线上的所有荆棘 | 沉：拾取时立刻 −3 步 | 刃 |
| 冫 | 浇灭周围两格内的所有火 | 反噬：用后被随机方向推 1d4 格 | 冰 |
| 工 | 砸开相邻一格的障碍物 | 重：每走 1 格多花 1 步（翻倍） | 筑 |
| 石 | 激活后免疫火与水 | 滞：每走 3 格额外 −1 步 | 磐 |
| 风 | 远程取走周围八格内的道具 | 窄：背包容量降为 1 | 漂 |
| 艹 | 激活后可通过树木与水 | 易燃：每走 4 格，若相邻有火则 −1 生命 | 野 |

> 「工」的代价是关卡设计的支点：**拿它砸开墙，然后立刻用 `E` 把它抹掉**，否则后面每一步都要花双倍。第四关就是专门教这件事的。

**汉字**（模 漠 蟆 墓 暮 幕）是拾取即得的永久增益，不占背包、不影响结局。

### 结局

走到门口时，看你**最先拾取的那个偏旁**。带两个偏旁时，先拿的那个定格成结局，另一个作为「双生」尾声出现 —— 同一个「莫」，只能填一次。

## 美术资源

`textures/` 里是 Kenney Scribble Platformer 的手绘素材（172 张，白底黑线）。当前映射：

| 用途 | 素材 |
|---|---|
| 地面 | *（不贴图，留白当纸）* |
| 荆棘 / 树木 / 障碍物 | `tile_spikes` / `tile_tree` / `tile_crate` |
| 火 / 水 / 门 | `pole_lantern` / `tile_water` / `tile_door` |
| 玩家 | `character_squareYellow` |
| 道具底框 | `ui_box` |

**换素材只需替换 `textures/` 下的同名文件**，或者在 `scripts/data.gd` 的 `TILE_TEX` / `TEX_PLAYER` / `TEX_ITEM` 里改文件名。

⚠️ 素材是**白底不透明**的，所以代码用 `modulate` 给白底染色来区分地形（`TILE_TINT`）。换素材时请让美术保持白底黑线的风格，或者改用带透明通道的图并同时调整 `TILE_TINT` 的浓淡——**地形主要靠颜色区分，颜色不能调得太接近**。

想一次看完所有素材：`Tools\Godot_console.exe res://scenes/sheet.tscn -- --page=0`（0~3 页）。

## 代码结构

```
project.godot        Data / Levels 两个 autoload
scenes/main.tscn     唯一场景（游戏本体）
scenes/sheet.tscn    素材联络表（开发工具）
scripts/data.gd      所有数据表：地块、偏旁、汉字、结局、美术映射
scripts/levels.gd    12 关手设计地图（ASCII，可直接编辑）
scripts/game.gd      全部游戏规则（不依赖 UI，可无头跑）
scripts/solver.gd    关卡求解器（用于验证关卡可通）
scripts/board.gd     纸面棋盘渲染
scripts/main.gd      UI、输入、调试参数
```

`game.gd` / `solver.gd` 完全不依赖 UI，所以能在 headless 下跑几千局测试。

### 改关卡

`scripts/levels.gd` 里直接改 ASCII 就行：

```
#  障碍物       .  地面        ^  荆棘        T  树木
F  火           W  水          S  起点        E  门
1火 2刂 3冫 4工 5石 6风 7艹    偏旁（决定结局）
a模 b漠 c蟆 d墓 e暮 f幕        汉字
```

改完**一定要跑一遍验证**，它会用求解器确认每一关真的可通、且步数上限不小于最优解：

```
Tools\Godot_console.exe --headless -- --levels
```

## 开发者命令

参数写在 `--` 之后。

```bash
# 验证 12 关全部可通（求解器）
Tools\Godot_console.exe --headless -- --levels

# 随机关卡：能不能解、要搜多少
Tools\Godot_console.exe --headless -- --random-solve=25

# 随机关卡压测：保底解端到端走通 + 500 次随机操作不崩
Tools\Godot_console.exe --headless -- --selftest=150

# 打印某张随机关卡的地图
Tools\Godot_console.exe --headless -- --dump-random --seed=9011

# 素材联络表（4 页）
Tools\Godot_console.exe res://scenes/sheet.tscn -- --page=2 --autoshot=res://_shots/sheet2.png

# 截图
Tools\Godot_console.exe -- --scenario=title --autoshot=res://_shots/t.png
Tools\Godot_console.exe -- --level=7 --autoshot=res://_shots/l8.png
Tools\Godot_console.exe -- --seed=9011 --keys=n --autoshot=res://_shots/r.png

# 把合成按键推进真实输入管线（验证 事件→viewport→_unhandled_input→游戏状态）
Tools\Godot_console.exe -- --trace-input --keys=right,right,f,1
```

`--scenario` 可选：`title` / `play` / `win` / `fail`。
带任何调试参数时不会写存档。

## 已知的取舍

策划文档里有两条效果依赖「地块寿命」这个从没定义的机制，v2 改成核心规则后它们失去了前提，换成了等价强度的替代：

| 位置 | 原文 | 实现 |
|---|---|---|
| 偏旁「工」·携带代价 | 携带时走过地块提前一轮消失 | 携带时每走 1 格多花 1 步（翻倍）——"拿它开路，然后赶紧扔掉" |
| 汉字「幕」·效果 | 走过地块存在时间 +1 回合 | 荆棘不再对你造成伤害 |

详细的设计推导与待策划确认的问题见 [`MVP设计文档.md`](MVP设计文档.md)。
